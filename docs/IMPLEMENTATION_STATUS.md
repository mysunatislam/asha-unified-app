Validation: full automated suite, new browser journeys and offline reload suite pass; real CPU model smoke benchmark and measured asset sizes are recorded. No additional learned weights or npm runtime dependencies were installed. See module-specific validation/source docs and `MODEL_BENCHMARKS.md`.

External blockers are deliberate, visible release gates rather than fabricated predictions: licensed/evaluated Bangladesh food classifier and segmentation/portion dataset; independent motion/gaze/reference user studies; low-end mobile measurements; clinician-authored symptom scenarios and clinical approval; production role identity/staffed-workflow decisions; provider privacy/security/regulatory assessment; release signing trust root. The code supplies usable manual/touch/local paths while those remain unresolved.
